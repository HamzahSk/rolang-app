Task: Build a Complete Tagalog A1 Learning Curriculum for Ro-Lang

Read "README.md" and inspect the entire existing project before making changes.

Objective

Create a comprehensive, structured Tagalog (Filipino) A1 beginner curriculum for Ro-Lang. The goal is to take a complete beginner from zero knowledge to a solid A1 foundation.

Focus ONLY on A1 for now. Do not create A2, B1, or higher-level content.

1. Complete Learning Materials

Create a well-organized curriculum covering all essential A1 topics, including:

- Alphabet, pronunciation, and basic phonetics.
- Greetings and introductions.
- Personal pronouns.
- Numbers, dates, days, and time.
- Family and relationships.
- Common objects and everyday vocabulary.
- Food, drinks, and ordering.
- Places and directions.
- Daily routines and activities.
- Basic questions and answers.
- Basic sentence structures.
- Essential particles and grammar.
- Common verbs and basic verb forms.
- Negation and simple sentence construction.
- Describing people, objects, and situations.

Make the curriculum progressive, with lessons arranged in a logical learning sequence.

2. Vocabulary System

Provide a rich A1 vocabulary collection.

Each entry should include:

- Tagalog word or expression.
- Pronunciation using Latin spelling where necessary.
- Indonesian translation.
- English translation when appropriate.
- Part of speech.
- Example sentence in Tagalog.
- Complete Indonesian sentence translation.
- Contextual explanation when necessary.

Include common words, useful expressions, phrases, and essential everyday vocabulary.

3. Flashcards and Review

Create flashcard-ready content for all important vocabulary and expressions.

Include:

- Tagalog → Indonesian.
- Indonesian → Tagalog.
- Word recognition.
- Contextual sentence completion.
- Basic grammar practice.

Integrate everything with the existing vocabulary and spaced-repetition review system. Avoid creating a separate learning system.

4. Stories and Reading Materials

Create multiple original A1 Tagalog stories across different themes:

- Everyday life.
- Introducing yourself.
- Family and friends.
- School life.
- Food and shopping.
- Traveling.
- Friendship and simple romance.
- Daily conversations.

Requirements:

- Stories must be complete and coherent, not disconnected paragraphs.
- Use natural, beginner-friendly Tagalog.
- Gradually introduce new vocabulary and grammar.
- Provide complete Indonesian translations.
- Include a dictionary entry for every meaningful word or expression.
- Reuse previously introduced vocabulary to reinforce learning.

5. Dialogue and Conversation

Create realistic conversations for common situations.

Each dialogue should include:

- Tagalog conversation.
- Pronunciation guide where useful.
- Indonesian translation.
- Vocabulary breakdown.
- Grammar explanations.
- Short comprehension exercises.

Prioritize natural expressions actually used by Filipino speakers rather than overly formal textbook language.

6. Illustrations and Visual Assets

Add original flat vector-style illustrations to make lessons more engaging.

Visual direction:

- Modern flat vector illustration.
- Clean geometric shapes.
- Soft, harmonious colors.
- Friendly characters and expressive faces.
- Consistent visual identity throughout the app.
- Suitable for language-learning educational content.

Use illustrations for vocabulary categories, stories, dialogues, and important lessons where they provide meaningful context.

Generate or create actual image assets and integrate them into the application. Do not just add image placeholders or descriptions.

Keep assets optimized for Android and avoid unnecessarily large files.

7. Content Quality

This is particularly important:

- Ensure Tagalog grammar and translations are accurate.
- Distinguish Tagalog from English-influenced Filipino expressions.
- Explain grammar concepts in simple Indonesian.
- Use natural Filipino examples.
- Avoid repetitive or meaningless content.
- Do not generate random vocabulary just to increase content quantity.
- Ensure every vocabulary item used in stories and lessons has proper dictionary coverage.
- Validate all content before integrating it.

8. Application Integration

Inspect the existing architecture and reuse its current systems:

- Existing curriculum and language-level models.
- Story catalog and reading interface.
- Vocabulary database.
- Flashcards and review system.
- Spaced repetition scheduler.
- Existing offline corpus.
- Existing illustrations and asset-loading mechanisms, if available.

All Tagalog A1 materials must work offline and be available immediately after installation.

Do not break existing English, Indonesian, or other language-learning functionality.

Preserve existing database migrations and learning progress.

9. Validation

After implementation:

- Validate the complete corpus.
- Check dictionary coverage for all stories.
- Verify translations and vocabulary references.
- Check that all lessons appear in the correct order.
- Verify flashcards and review integration.
- Run existing unit tests and lint.
- Build the Android debug APK.

Fix any issues introduced by your changes.

Final Goal

Deliver a genuinely useful and comprehensive Tagalog A1 course, not just a small vocabulary pack or a few sample stories.

Prioritize content quality, completeness, natural language usage, and seamless integration with Ro-Lang.

Work directly within the existing project. Avoid unnecessary architectural rewrites or unrelated UI changes.
